## Spacing Scale

Carries forward from Phase 17 UI-SPEC (Tailwind CSS v4 defaults, multiples of 4):

| Token | Value | Usage                                                       |
| ----- | ----- | ----------------------------------------------------------- |
| xs    | 4px   | Icon gaps, cycle card status dot spacing, filter chip gaps  |
| sm    | 8px   | Compact element spacing, progress bar inner padding         |
| md    | 16px  | Default element spacing, card inner padding, button padding |
| lg    | 24px  | Section padding, Cycle/Module list card padding             |
| xl    | 32px  | Layout gaps between columns in detail page (dual-panel)     |
| 2xl   | 48px  | Major section breaks, empty state vertical spacing          |
| 3xl   | 64px  | Page-level spacing, modal/popover from edges                |

Exceptions:

- **Progress bar**: Height at 8px (cycle progress, module progress) — Plane convention from `cycles/active-cycle/`
- **Cycle card compact**: List-item card min-height at 56px (Plane `cycles/list/list-item.tsx` pattern)
- **Burndown chart**: SVG viewBox padding at 12px inner, 24px outer (Plane `cycles/analytics-sidebar/` pattern)
- **Touch targets**: Cycle/Module delete icon buttons at minimum 28px height (Plane convention)
