       - markAsRead(notificationId: string): 在本地 MOCK_NOTIFICATIONS 中设置 read_at
       - markAllAsRead(workspaceId: string): 批量设置
       - export default new NotificationService()

    5. 创建 `src/lib/hooks/use-notifications.ts`：
       - 遵循 use-pages.ts / use-page-mutations.ts 模式
       - useNotifications(workspaceId: string) → useQuery<TNotification[]>, queryKey: ["workspace-notifications", workspaceId]
       - useUnreadCount(workspaceId: string) → useQuery<TUnreadNotificationsCount>, queryKey: ["workspace-unread-count", workspaceId]
       - useNotificationMutations() → 返回 { markAsRead, markAllAsRead } 两个 useMutation
         - markAsRead: mutationFn(notificationId), onSuccess invalidateQueries(["workspace-notifications", workspaceId]) — 注意 mutation 本身无法获取 workspaceId，需要传入 { notificationId, workspaceId } 作为参数
         - markAllAsRead: mutationFn(workspaceId), onSuccess invalidateQueries(["workspace-notifications", workspaceId])
       - 导出这三个 hooks

    6. 注册到 `app/store/root.store.ts`：

       - 在 ICoreRootStore interface 添加 `notification: INotificationStore;`
       - 在 CoreRootStore class 添加 notification 属性和构造中 new NotificationStore()
