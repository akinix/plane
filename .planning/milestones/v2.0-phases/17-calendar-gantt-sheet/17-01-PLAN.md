    创建 `app/components/issues/filters/use-filters.ts`：

    实现 `useFilters` hook（per D-P17-11：TanStack Query + URL query params 同步）：
    1. 使用 `useSearchParams` 从 URL query params 读取初始筛选状态
    2. 使用 `useQuery` 管理筛选状态（queryKey: ["issue-filters", projectId]）
    3. URL ↔ TanStack Query 双向同步：
       - URL params → state: 初始化时从 URL 读取（支持空值兜底默认值）
       - state → URL params: 每次筛选变更时 `setSearchParams` 更新 URL
    4. 返回接口：
       - `filters: TFilterCriteria` — 当前筛选条件
       - `setFilters(filters: Partial<TFilterCriteria>): void` — 设置筛选条件（浅合并）
       - `clearFilters(): void` — 清除所有筛选
       - `hasActiveFilters: boolean` — 是否有活跃筛选
       - `isLoading: boolean` — 加载状态

    URL query params 映射规则：
    - `state` → 逗号分隔的 stateIds
    - `priority` → 逗号分隔的 priorityIds
    - `assignee` → 逗号分隔的 assigneeIds
    - `labels` → 逗号分隔的 labelIds
    - `search` → searchQuery

    创建 `app/components/issues/filters/use-sorting.ts`：

    实现 `useSorting` hook（FILT-02，同步到 URL）：
    1. 从 URL query params 读取 `sort_by` 和 `sort_direction`
    2. 使用 useState 管理排序状态
    3. URL 同步: setSearchParams 更新
    4. 返回接口：
       - `sortConfig: TSortConfig` — 当前排序配置
       - `setSortBy(field: string): void` — 设置排序字段（相同字段翻转方向）
       - `setSortDirection(dir: "asc" | "desc"): void` — 直接设置方向
       - `sortedIssues(issues: TIssue[]): TIssue[]` — 对传入的 issue 数组执行客户端排序的实用函数

    排序逻辑（用在 sortedIssues 方法中）：
    - 按 sortConfig.sortBy 字段名排序
    - null/undefined 值排在末尾
    - String 用 localeCompare，Number 用差值，其他返回 0
    - 方向: asc=1, desc=-1

  </action>
  <acceptance_criteria>
