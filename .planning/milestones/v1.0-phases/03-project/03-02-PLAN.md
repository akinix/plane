    - ToTable "Projects", schema `ProjectModuleConstants.SchemaName`
    - Key: Id (Guid)
    - Name: IsRequired, HasMaxLength(255)
    - Identifier: IsRequired, HasMaxLength(12)
    - Slug: IsRequired, HasMaxLength(SlugMaxLength=100). Unique index WITHOUT filter (slug is modified on delete → always unique)

    - OwnerId: IsRequired

    - Name unique within workspace: `HasIndex(x => new { x.TenantId, x.Name }).IsUnique().HasDatabaseName("IX_Projects_Tenant_Name").HasFilter("[DeletedOnUtc] IS NULL")`
    - Slug unique: `HasIndex(x => x.Slug).IsUnique().HasDatabaseName("IX_Projects_Slug")` — no filter (slug is epoch-modified on delete)
    - OwnerId performance index: `HasIndex(x => x.OwnerId).HasDatabaseName("IX_Projects_Owner")`
    - Audit/soft-delete columns: CreatedOnUtc IsRequired, CreatedBy HasMaxLength(450), LastModifiedBy HasMaxLength(450), DeletedBy HasMaxLength(450)
    - NO explicit `.IsMultiTenant()` call — ApplyTenantIsolationByDefault auto-applies it since Project is IHasTenant (not IGlobalEntity)

| Threat ID     | Category               | Component                 | Disposition | Mitigation Plan                                                                                                                     |

| T-3-domain-01 | Information Disclosure | Project.IHasTenant        | mitigate    | Project implements IHasTenant (not IGlobalEntity), BaseDbContext auto-filters by TenantId — no tenant-leak at query level           |
| T-3-domain-02 | Tampering              | SoftDelete slug release   | mitigate    | SoftDelete appends `__{epoch}` to Slug, releasing original value. Slug index is unconditional (no filter).                          |
