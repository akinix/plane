  <action>
    在 `FlowApiService` 类中添加以下方法（在现有 `get / post / put / patch / delete / request` 方法之后）：

    **1. 新增导入**：在文件顶部添加 `TPaginatedResponse` 的导入：
    ```typescript
    import type { TPaginatedResponse } from "@/lib/types/pagination";
    ```

    **2. `unwrapPaginated<T>(response: AxiosResponse<TPaginatedResponse<T[]>>): T[]`** — 内部辅助方法
    - 提取 `response.data.results`
    - 如果 `results` 是数组，返回它
    - 如果 `data` 本身就是数组，返回它（fallback）
    - 类型签名：
    ```typescript
    protected unwrapPaginated<T>(
      response: AxiosResponse
    ): T[] {
      const data = response.data;
      if (data && Array.isArray(data.results)) {
        return data.results;
      }
      if (Array.isArray(data)) return data;
      return data;
    }
    ```

    **3. `getList<T>(url: string, params?: Record<string, unknown>, config?: AxiosRequestConfig): Promise<T[]>`** — 分页列表查询
    - 调用 `this.get()` 方法
    - 通过 `unwrapPaginated` 自动解包 `results` 数组
    - 类型签名：`Promise<T[]>`
    ```typescript
    async getList<T>(
      url: string,
      params: Record<string, unknown> = {},
      config: AxiosRequestConfig = {}
    ): Promise<T[]> {
      const response = await this.get(url, { params, ...config });
      return this.unwrapPaginated<T>(response);
    }
    ```

    **4. `getOne<T>(url: string, config?: AxiosRequestConfig): Promise<T>`** — 单对象查询
    - 调用 `this.get()` 方法
    - 直接返回 `response.data`
    ```typescript
    async getOne<T>(
      url: string,
      config: AxiosRequestConfig = {}
    ): Promise<T> {
      const response = await this.get(url, config);
      return response.data as T;
    }
    ```

    **5. `postList<T>(url: string, data?: unknown, config?: AxiosRequestConfig): Promise<T[]>`** — POST 分页查询（适用于复杂筛选条件通过 POST 体提交的场景）
    - 调用 `this.post()` 方法
    - 通过 `unwrapPaginated` 自动解包
    ```typescript
    async postList<T>(
      url: string,
      data: unknown = {},
      config: AxiosRequestConfig = {}
    ): Promise<T[]> {
      const response = await this.post(url, data, config);
      return this.unwrapPaginated<T>(response);
    }
    ```

    **6. `postOne<T>(url: string, data?: unknown, config?: AxiosRequestConfig): Promise<T>`** — POST 创建/操作返回单对象
    - 调用 `this.post()` 方法
    - 直接返回 `response.data`
    ```typescript
    async postOne<T>(
      url: string,
      data: unknown = {},
      config: AxiosRequestConfig = {}
    ): Promise<T> {
      const response = await this.post(url, data, config);
      return response.data as T;
    }
    ```

    **7. `patchOne<T>(url: string, data?: unknown, config?: AxiosRequestConfig): Promise<T>`** — PATCH 更新返回单对象
    ```typescript
    async patchOne<T>(
      url: string,
      data: unknown = {},
      config: AxiosRequestConfig = {}
    ): Promise<T> {
      const response = await this.patch(url, data, config);
      return response.data as T;
    }
    ```

    **8. `putOne<T>(url: string, data?: unknown, config?: AxiosRequestConfig): Promise<T>`** — PUT 更新返回单对象
    ```typescript
    async putOne<T>(
      url: string,
      data: unknown = {},
      config: AxiosRequestConfig = {}
    ): Promise<T> {
      const response = await this.put(url, data, config);
      return response.data as T;
    }
    ```

    **设计原则：**
    - 所有新方法保持与现有方法一致的异常处理（通过响应拦截器传递）
    - 方法名约定：`{httpVerb}{ReturnType}`，如 `getList`（GET 返回列表）、`getOne`（GET 返回单对象）
    - 不修改现有 `get/post/put/patch/delete` 方法，保持向后兼容
    - 现有 `get()` 仍然可用，不会破坏已有的 Service 代码
