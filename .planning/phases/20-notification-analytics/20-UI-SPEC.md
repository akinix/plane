## Spacing Scale

Existing 8-point grid. All values in px, multiples of 4.

| Token | Value | Usage                                            |
| ----- | ----- | ------------------------------------------------ |
| xs    | 4px   | Badge dot spacing, inline icon gaps              |
| sm    | 8px   | Notification item padding, icon-to-text gap      |
| md    | 16px  | Card padding, button horizontal padding          |
| lg    | 24px  | Section padding, chart container margin          |
| xl    | 32px  | Layout gaps between major sections               |
| 2xl   | 48px  | Page-level spacing between sections              |
| 3xl   | 64px  | Dashboard top padding, max content width padding |

Exceptions:

- Notification bell badge: 6px diameter dot (absolute positioned, not on grid)
- Chart tooltip: 8px padding inside (matches card inner padding)
- Sidebar collapsed: 56px (w-14), expanded: 256px (w-64) — override per existing layout

## Typography

Exactly 4 sizes: 13px, 14px, 18px, 24px. Never use arbitrary font-size values outside this set.

| Role                             | Size | Weight         | Line Height | CSS Class / Token                            |
| -------------------------------- | ---- | -------------- | ----------- | -------------------------------------------- |
| Body                             | 14px | 400 (normal)   | 1.5         | `text-sm`                                    |
| Label / meta / badge / timestamp | 13px | 400 (normal)   | 1.4         | `text-13 text-custom-text-300`               |
| Subheading / section title       | 18px | 600 (semibold) | 1.3         | `text-18 font-semibold` (Plane custom)       |
| Page heading                     | 24px | 600 (semibold) | 1.2         | `text-2xl font-semibold`                     |
| Chart axis label                 | 13px | 400 (normal)   | 1.0         | `text-13 text-custom-text-300` uppercase     |
| Table header                     | 13px | 600 (semibold) | 1.4         | `text-13 font-semibold text-custom-text-300` |

### Copy Language

All labels, empty states, tooltips, and error messages are Chinese (Simplified). No i18n framework — plain string literals.

## Page Specifications

### 1. Notifications Page

**Route:** `/workspaces/:workspaceId/notifications`

**Layout:**

- Standard workspace layout (sidebar + top-bar + content area)
- Top-bar Bell icon shows unread count badge (already exists as placeholder in `top-bar.tsx`)
- Clicking Bell navigates to `/workspaces/:workspaceId/notifications`
- Full page replaces main content area (Outlet)

**Header:**

- Title: "通知" (h1, text-2xl font-semibold)
- Actions: "全部标记已读" button (mark-all-read) — direct operation, no confirmation dialog
- Refresh button (RefreshCw icon) — for manual refresh per D-P20-01

**List:**

- Flat vertical list, no Tab switching per D-P20-08 simplified UI
- Single column: "全部通知" (no "提及我的" tab)
- Items ordered by `created_at` descending

**Notification Item:**

```
+----------------------------------------------+
| [Avatar]  [Actor name] [verb description]    |
|           [issue title / content preview]     |
|           [timestamp]              [Unread·]  |
+----------------------------------------------+
```

- **Avatar** (32x32, from `src/lib/ui/avatar/`): triggered_by user avatar
- **First line**: actor display_name + action context (e.g. "张三 更新了优先级")
- **Second line**: Issue title or activity new_value (truncated single line, `truncate`)
- **Third line**: relative timestamp via date-fns `formatDistanceToNow`
- **Read state**: left border indicator (2px solid brand color for unread, transparent for read) OR filled blue dot at right edge (existing Plane pattern). Follow Plane read/unread visual pattern.
- **Background**: unread gets `bg-custom-background-80`, read gets transparent
- **Hover**: `bg-custom-background-70` on hover
- **Click**: navigate via ControlLink to associated Issue or comment per NOTI-04

**Mark-as-read interaction:**

- Single item: swipe/click the item marks it as read (optimistic update via MobX store)
- Mark-all-read: Mutate store, re-render all items as read state

**Empty State:**

- Centered vertically and horizontally
- Bell icon (size-12, text-custom-text-300)
- "暂无通知" heading
- No body text (self-explanatory)

**Loading Skeleton:**

- 6x Loader.Item rows, each with avatar circle (size-8) + 2 text lines (w-3/4 + w-1/2)
- Use existing `Loader` component from `src/lib/ui/loader.tsx`

### 2. Analytics Dashboard Page

**Route:** `/workspaces/:workspaceId/analytics`

**Layout:**

- Standard workspace layout
- Max content width: max-w-6xl mx-auto
- Two tabs: "概览" (default active) | "工作项"

**Header:**

- Title: "分析" (h1, text-2xl font-semibold)
- Project filter dropdown (multi-select, uses existing Dropdown component)

**Overview Tab Components** (top to bottom):

1. **Insight Cards** (4-column grid on `>=1024px`, 2-column on 768-1023px)
   - Card count: 4 key metrics
   - Each card: icon (optional) + label + count value
   - Cards styled with existing Card component, `gap-4` spacing
2. **Radar Chart** (project comparison)
   - X-axis: projects
   - Metrics: completed count, in-progress, backlog
   - Uses `AnalyticsRadarChart` component wrapping recharts RadarChart

3. **Active Projects List** (simple list below chart)
   - Project name + emoji + completion percentage
   - Click navigates to project-level analytics

**Work Items Tab Components** (top to bottom):

1. **Area Chart** (created vs resolved trend over time)
   - X-axis: date (monthly grouping)
   - Y-axis: count
   - Two areas: "已创建" (stroke blue) + "已完成" (stroke green)
   - Uses `AnalyticsAreaChart` wrapping recharts AreaChart

2. **Bar Chart** (custom insight distribution)
   - X-axis: configurable (priority, state group, assignee, etc.)
   - Y-axis: work item count
   - Stacked bars or grouped bars
   - Uses `AnalyticsBarChart` wrapping recharts BarChart

3. **Data Table** (below charts)
   - Columns: category | count | percentage of total
   - Sortable by count (default desc)
   - CSV export button (Download icon, top-right of table)
   - CSV export uses `export-to-csv` package per D-P20-03

**Filter Bar:**

- Project multi-select dropdown (use existing `CustomSearchSelect`)
- Date range filter (presets: 昨天 / 最近7天 / 最近30天 / 最近3个月)
- Refresh button
- Applied filters shown as tags (x to remove)

**Empty State:**

- Centered vertically and horizontally
- BarChart3 icon (size-12, text-custom-text-300)
- "暂无分析数据" heading
- "选择项目后查看分析图表" body text

**Loading Skeleton:**

- 4 Card skeleton items (w-full h-24) in grid
- 2 Chart skeleton items (w-full h-80)

### 3. Top-bar Bell Integration

**File:** `app/components/navigation/top-bar.tsx`

**Modifications:**

- Replace existing placeholder Bell button with NotificationBell component
- Animated solid/outline bell state (outline for no unread, solid for has unread)
- Unread count display: numeric when 1-99, "99+" when >= 100
- Badge styling: red dot with white text count, absolute positioned top-right
- Click: navigate to `/workspaces/{workspaceId}/notifications`

**Count state:**

- 0 unread: no badge dot, outline bell icon
- > = 1 unread: filled dot/count badge, solid bell icon

## Interaction Contracts

### Notification Interactions

| Interaction             | Trigger                     | Behavior                                                                     |
| ----------------------- | --------------------------- | ---------------------------------------------------------------------------- |
| Click notification item | Click on item row           | Navigate to associated Issue/comment via ControlLink (// FLOW: per NOTI-04)  |
| Mark single as read     | Click item (implied)        | Optimistic: set `read_at` in store, update item style to read state          |
| Mark all as read        | Click "全部标记已读" button | Mutate all unread items to read state in store; UI preserves scroll position |
| Manual refresh          | Click refresh icon          | Refetch notification query via TanStack Query                                |
| Hover item              | Mouse enter                 | Background `bg-custom-background-70`, cursor pointer                         |
| Loading items           | Initial load                | Show NotificationSkeleton (6 items)                                          |
| Empty state             | 0 results                   | Show NotificationEmptyState                                                  |
| Error state             | API failure                 | Inline error banner: "加载通知失败，请重试" + retry button                   |

### Analytics Interactions

| Interaction       | Trigger                      | Behavior                                                       |
| ----------------- | ---------------------------- | -------------------------------------------------------------- |
| Tab switch        | Click tab (概览 / 工作项)    | Preserve selected project filter across tabs                   |
| Project filter    | Select from dropdown         | Refetch analytics data, recompute chart and table              |
| Date range change | Select range preset          | Refetch trend data for area chart                              |
| Refresh charts    | Click refresh icon           | Refetch all analytics queries                                  |
| Hover chart point | Mouse enter chart data point | Show tooltip with category + value (recharts default tooltip)  |
| Export CSV        | Click download button        | Generate CSV from current table data, trigger download         |
| Table sort        | Click column header          | Toggle sort asc/desc, re-render table                          |
| Loading charts    | Initial load                 | Show AnalyticsSkeleton                                         |
| Empty data        | 0 results                    | Show AnalyticsEmptyState                                       |
| Error state       | API failure                  | Inline error banner: "加载分析数据失败，请重试" + retry button |

### Responsive Behavior (UI-06 — Plan 03)

All pages must function at viewport widths >= 768px.

| Breakpoint          | Behavior                                                                                                                |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| >= 1024px (desktop) | Full layout: sidebar expanded (w-64), 4-column insight grid, full-width charts                                          |
| 768-1023px (tablet) | Sidebar collapsed by default (w-14, expandable on toggle); 2-column insight grid; charts stack vertically (one per row) |
| < 768px             | Out of scope per requirements                                                                                           |

**Specific responsive contracts:**

- Notification list: single column at all widths >= 768px, no horizontal scroll needed
- Insight cards: `grid-cols-4` -> `grid-cols-2` at 1023px
- Chart containers: `flex-row` -> `flex-col` at 1023px
- Data table: horizontal scroll only if more than 5 columns; CSV as overflow escape hatch
