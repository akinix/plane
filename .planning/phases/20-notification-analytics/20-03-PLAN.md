  <action>
    1. 检查 `app/store/workspace.store.ts` 确认已有 sidebarCollapsed 状态：
       - 如果已有 sidebarCollapsed: boolean 和 setSidebarCollapsed action，则跳过
       - 如果不存在则需要添加（从现有 types.ts 可知 IWorkspaceStore 已有 sidebarCollapsed 和 setSidebarCollapsed，确认实际实现覆盖）

    2. 侧边栏响应式逻辑 `app/components/sidebar/workspace-sidebar.tsx`：
       - 使用 `useWindowSize` 或 media query hook 监听窗口宽度（优先使用 CSS media query 而非 JS 监听）
       - 方法：通过 Tailwind CSS 的 `lg:` breakpoint（1024px）控制：
         - 默认 expanded 时: w-64（desktop）
         - 默认 collapsed 时: w-14（tablet < 1024px）
         - 使用 `cn()` 组合 Tailwind classes: `cn("w-64 lg:w-64", { "w-14": sidebarCollapsed })` 或者更精确：
         ```tsx
         className={cn(
           "fixed left-0 top-0 z-30 flex h-full flex-col border-r border-custom-border-200 bg-custom-sidebar-background-100 transition-all duration-200",
           sidebarCollapsed ? "w-14" : "w-64"
         )}
         ```
       - 添加响应式 toggle: 在 < 1024px 时 sidebar 默认 collapsed，但用户可切换
       - 监听窗口宽度变化：使用 useEffect + window.addEventListener("resize")，当宽度 < 1024 且 sidebar 展开时，自动折叠；反之如果宽度 >= 1024 且 sidebar 折叠，自动展开
       - 注意防抖（debounce）resize 事件

    3. 布局适配 `app/layouts/workspace-layout.tsx`：
       - 主内容区域的 margin-left 根据 sidebarCollapsed 状态调整：
         - collapsed: ml-14
         - expanded: ml-64
       - 使用 transition 使 margin 变化平滑（transition-all duration-200）
       - 确保 Outlet 内容区域不溢出

    4. 键盘快捷键支持（可选增强）：
       - Cmd/Ctrl + B 切换 sidebar collapse（按现有访问性实践）

  </action>

    - 侧边栏在 >=1024px 下默认展开（w-64），可通过 toggle 折叠
    - resize 窗口时侧边栏自动适应 breakpoint
