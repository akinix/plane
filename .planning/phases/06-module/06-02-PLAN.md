    **ListModulesQuery（IQuery&lt;List&lt;ModuleDto&gt;&gt;）:**
    - `[JsonIgnore] public Guid ProjectId { get; set; }`
    - `public string? Status { get; set; }` — "backlog" | "planned" | "in-progress" | "paused" | "completed" | "cancelled" | "all"（默认 "all"）

    **ListModulesEndpoint:**
    - `MapGet("/", ...)` with `[RequireAuthorization]`
    - 签名: `async (Guid projectId, string? status, IMediator mediator, CancellationToken ct)`
    - 设置 `query.ProjectId = projectId; query.Status = status` → mediator.Send → Ok
    - Produces&lt;List&lt;ModuleDto&gt;&gt;

    **ListModulesQueryHandler:**
    - 构造注入 `WorkItemsDbContext _db`
    - 查询模式（比 ListCycles 简单，因为 status 是存储字段，可在 EF 查询中直接过滤）:
      ```csharp
      var query = _db.Modules
          .AsNoTracking()
          .Where(m => m.ProjectId == query.ProjectId && !m.IsDeleted && m.ArchivedAt == null);

      // Apply status filter (stored field — can filter at DB level)
      if (!string.IsNullOrWhiteSpace(query.Status) && query.Status != "all")
      {
          query = query.Where(m => m.Status == query.Status);
      }

      var modules = await query
          .OrderBy(m => m.SortOrder)
          .ToListAsync(cancellationToken);

      // 对每个 Module 查询注释字段
      var result = new List<ModuleDto>();
      foreach (var m in modules)
      {
          var totalIssues = await _db.ModuleIssues
              .CountAsync(mi => mi.ModuleId == m.Id && !mi.IsDeleted, ct);
          // ... similar for other annotation fields

          result.Add(ModuleDtoMapper.ToDto(
              m, totalIssues, completedIssues, cancelledIssues,
              startedIssues, unstartedIssues, backlogIssues));
      }
      return result;
      ```
