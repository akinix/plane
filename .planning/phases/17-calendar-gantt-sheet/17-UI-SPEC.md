## Spacing Scale

Declared values (Tailwind CSS v4 defaults, multiples of 4):

| Token | Value | Usage                                                       |
| ----- | ----- | ----------------------------------------------------------- |
| xs    | 4px   | Icon gaps, view toggle inner padding, filter chip gaps      |
| sm    | 8px   | Compact element spacing, icon-only touch target padding     |
| md    | 16px  | Default element spacing, card inner padding, button padding |
| lg    | 24px  | Section padding, page header content padding                |
| xl    | 32px  | Layout gaps, column gaps in kanban/spreadsheet              |
| 2xl   | 48px  | Major section breaks, empty state vertical spacing          |
| 3xl   | 64px  | Page-level spacing, modal/popover from edges                |

Exceptions:

- **Touch targets**: Filter bar buttons, day-tile date cells at minimum 28px height (Plane gantt BLOCK_HEIGHT = 44px, header HEIGHT = 48px per gantt-chart constants)
- **Drag handle**: 24px wide touch target (Plane convention from existing DragHandle)

### Accent Reserved For

The accent color (`--bg-accent-primary` / `brand-default`) is reserved for these specific elements ONLY:

1. "创建 Issue" primary CTA button
2. Active view toggle indicator (selected list/calendar/gantt/spreadsheet tab)
3. "清除筛选" active state text
4. "保存视图" primary action button
5. Calendar: today-column indicator, dragged issue highlight border
6. Gantt: progress bar fill, today marker line
7. Spreadsheet: active cell border, inline edit focus ring
8. Link text (`text-custom-primary-100`)
9. Selected/active filter chip border
10. Filter panel: active multi-select checkmark

## Interaction Contract

### Calendar View (CALN-01, CALN-02)

| Interaction           | Behavior                                                                                                           |
| --------------------- | ------------------------------------------------------------------------------------------------------------------ |
| View switch           | Calendar icon in view toggle → lazy loads CalendarView component                                                   |
| Month navigation      | Left/right arrow buttons in calendar header to switch months                                                       |
| Today jump            | "今天" button scrolls/animates to current day                                                                      |
| Issue display         | Issue blocks shown as colored pill cards on relevant day tiles                                                     |
| Dual-date span        | Issue with start_date + target_date spans multiple days (colored bar)                                              |
| Drag to reschedule    | Drag issue block from source day to destination day → optimistic update + API call via handleDragDrop (Plane util) |
| Quick-add             | Click empty day tile → inline quick-add input (Plane quick-add-issue-actions pattern)                              |
| Click issue           | Open issue detail page (same as Phase 16 detail page flow)                                                         |
| Loading               | Month spinner while issues load (lazy range: date-fns calculated start/end of visible month)                       |
| Empty month           | "该月份没有 Issue" centered in canvas area                                                                         |
| Current day highlight | Today's column/cell gets accent border indicator                                                                   |
| Epics/Sub-issues      | CalendarIssueBlock supports isEpic variant (from Fork source)                                                      |

### Gantt Chart View (GANT-01, GANT-02)

| Interaction             | Behavior                                                                               |
| ----------------------- | -------------------------------------------------------------------------------------- |
| View switch             | GitBranch icon in view toggle → lazy loads GanttView component                         |
| Time axis               | Horizontal date axis showing days/weeks/months/quarters per zoom level                 |
| Issue bars              | Horizontal bars positioned by start_date → target_date span                            |
| Progress bar            | Bar fill percentage = closed sub-issues / total sub-issues (0 or 100 if no sub-issues) |
| Dependency lines        | SVG arrow lines between dependent issues (GANT-02, read-only in Phase 17)              |
| Zoom levels             | 4 levels: day / week / month / quarter (D-P17-16)                                      |
| Scroll                  | Horizontal scroll for time axis, vertical scroll for issue list                        |
| Sidebar                 | Left sidebar with issue list (name, identifier, assignee) — SIDEBAR_WIDTH = 360px      |
| Empty state             | "暂无 Issue" with body about creating issues with dates                                |
| Context padding         | Default view: complete date + 7 days after, start date - 7 days before                 |
| Click bar               | Open issue detail page                                                                 |
| Drag to resize bar ends | Extend/shorten issue duration (Plane gantt bar-drag pattern)                           |
| Drag to move bar        | Shift entire timeframe (Plane gantt bar-move pattern)                                  |

### Spreadsheet View (SHEE-01, SHEE-02)

| Interaction       | Behavior                                                                            |
| ----------------- | ----------------------------------------------------------------------------------- |
| View switch       | Table icon in view toggle → lazy loads SpreadsheetView component                    |
| Column headers    | Horizontal scrollable header row with field names                                   |
| Cell inline edit  | Single-click cell → inline editor replaces display value (D-P17-08)                 |
| Property editors  | Priority renders dropdown, assignee renders user selector, etc.                     |
| Batch edit        | Multi-select rows → bulk action bar appears (same pattern as Phase 16)              |
| Virtual scroll    | Plane spreadsheet implements virtualized rows for large datasets                    |
| Column resize     | Drag column header borders to resize (Plane spreadsheet-header-column pattern)      |
| Empty state       | "暂无 Issue" centered                                                               |
| Loading           | Skeleton row placeholders                                                           |
| Click cell → edit | Click cell → enters edit mode; click outside or press Enter → save; Escape → cancel |
| Auto-save         | Debounce: 800ms after last keystroke (Claude's discretion from CONTEXT)             |

### Filter Engine (FILT-01~04)

| Interaction         | Behavior                                                                                 |
| ------------------- | ---------------------------------------------------------------------------------------- |
| Quick filter chips  | State / Priority / Assignee dropdown filters shown by default                            |
| Extended panel      | "更多" button expands filter panel with additional criteria (labels, created date, etc.) |
| Active chip display | Selected filters shown as removable chips below filter bar                               |
| Chip remove         | Click X on chip → removes that filter value                                              |
| Clear all           | "清除" link appears when any filter active → removes all filters                         |
| Search              | Text input with debounced search query (300ms)                                           |
| Sort selector       | Dropdown with field options + asc/desc toggle                                            |
| Column selector     | "自定义列" button opens ColumnSelector overlay with checkboxes                           |
| Save view           | "保存视图" button → modal with name input → POST to IssueView API                        |
| Filter sync         | URL query params update on every filter change (shareable URLs)                          |
| Group by            | Dropdown: None / State / Priority / Assignee / Created By                                |
| Sub-group by        | Dropdown: None / State / Priority (appears after group-by selection)                     |

## State Visual Patterns

### Loading State

```
<div className="flex items-center justify-center h-full text-custom-text-400">
  加载中...
</div>
```

- Calendar: Month spinner overlay while lazy-loading issue range
- Gantt: Skeleton bar placeholders while loading issues
- Spreadsheet: Skeleton row placeholders
- Filter bar: All dropdowns disabled during loading
