      3. 验证目标 Cycle 未 COMPLETED: `newCycle.EndDate >= DateTimeOffset.UtcNow` 或 EndDate 为空 → 允许；否则 throw CustomException("Cannot transfer to a completed cycle.")

      5. `sourceCycle.FreezeSnapshot(snapshotJson)` — 使用 System.Text.Json.JsonSerializer 序列化 CycleProgressSnapshot
      6. 查询源 Cycle 中状态为未完成（backlog/unstarted/started）的 CycleIssues:
         - 通过 Join Issues 表获取 StateId，但更简单的方式：查询所有属于该 Cycle 的非删除 Issue，过滤掉 Completed/Cancelled 状态的
         - 注意: 因为状态在 State 表中，需要 Join: CycleIssue → Issue → State
         - 或者采用更简单的 Plane 兼容方式：查询所有 `!ci.IsDeleted` 的 CycleIssues，排除已完成的 Issue（通过 Issue.CompletedAt 判断）
         ```csharp
         var incompleteIssueIds = await _db.Set<CycleIssue>()
             .Where(ci => ci.CycleId == cycleId && !ci.IsDeleted)
             .Join(_db.Issues.Where(i => !i.IsDeleted && i.CompletedAt == null),
                 ci => ci.IssueId, i => i.Id, (ci, i) => ci.Id)
             .ToListAsync(cancellationToken);
         ```
      7. Bulk update: 将这些 CycleIssues 的 CycleId 改为 NewCycleId
         - 注意: CycleIssue 的 CycleId 是 private setter，需要通过领域方法更新或直接使用 EF 属性
         - 推荐: 使用 `_db.Set<CycleIssue>().Where(ci => incompleteIssueIds.Contains(ci.Id)).ExecuteUpdateAsync()` 但注意 ISoftDeletable 和 IHasTenant 的冲突
         - 更安全的方式: 加载 CycleIssues 列表，逐个创建新的 CycleIssue（目标 Cycle），然后软删除旧的
         ```csharp
         foreach (var ciId in incompleteIssueIds)
         {
             var oldCi = await _db.Set<CycleIssue>().FindAsync(new object[] { ciId }, ct);
             if (oldCi != null)
             {
                 var newCi = CycleIssue.Create(oldCi.IssueId, command.NewCycleId);
                 _db.Set<CycleIssue>().Add(newCi);
                 oldCi.SoftDelete(DateTimeOffset.UtcNow);
             }
         }
         ```
