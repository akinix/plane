    **创建 ApiTokenService.cs:** 在 `Services/` 下。实现 `IApiTokenService` 接口：
    - 依赖注入: `IdentityDbContext`, `UserManager<FshUser>`, `ICurrentUser`, `ILogger<ApiTokenService>`
    - **CreateAsync:**
      1. 生成随机 Key: `"pk_" + RandomNumberGenerator.GetHexString(32)`
      2. 计算 SHA-256: `SHA256.HashData(Encoding.UTF8.GetBytes(rawKey))` → 转 hex string
      3. Prefix: `"pk_" + rawKey.Substring(3, 8)` （前 8 字符用于显示）
      4. 创建 `APIToken.Create(name, userId, hash, prefix, tenantId, expiredAt)`
      5. 保存到 DbContext
      6. 返回 `ApiTokenCreateResult`（包含明文 Token）
    - **ListForUserAsync:** 查询 `_dbContext.ApiTokens.Where(t => t.UserId == userId)`，映射为 `APITokenDto`
    - **RevokeAsync:** 查找 Token（验证 userId 匹配），调用 `token.Revoke()`，保存
    - **ValidateAndGetOwnerAsync:**
      1. 计算输入 Key 的 SHA-256 哈希
      2. 查询 `_dbContext.ApiTokens.Include(t => t.User).FirstOrDefaultAsync(t => t.TokenHash == hash)`
      3. 检查 `IsActive`, `IsExpired()`
      4. 有效则 `token.RecordUsage()`, `SaveChangesAsync`
      5. 查询用户角色和权限，返回 `ApiKeyValidationResult`
      6. 所有异步操作传递 CancellationToken

        public string? Next { get; init; }
        public string? Previous { get; init; }
        public IReadOnlyCollection<T> Results { get; init; } = Array.Empty<T>();

        public static PlanePagedResult<T> FromPagedResponse(
            PagedResponse<T> paged, HttpContext httpContext)
        {
            // 构建 next/previous URL，保留原始查询参数
            var baseUrl = $"{httpContext.Request.Scheme}://{httpContext.Request.Host}{httpContext.Request.Path}";
            var query = httpContext.Request.QueryString.Value ?? "";

            return new PlanePagedResult<T>
            {
                Count = paged.TotalCount,
                Results = paged.Items,
                Next = paged.HasNext ? ReplacePageParam(baseUrl, query, paged.PageNumber + 1) : null,
                Previous = paged.HasPrevious ? ReplacePageParam(baseUrl, query, paged.PageNumber - 1) : null,
            };
        }

        private static string ReplacePageParam(string baseUrl, string query, int page)
        {
            // 使用 QueryHelpers 或手动替换 page 参数
            // 确保保留其他查询参数（筛选、排序等）
        }
    }

| Boundary                                 | Description                                               |
| ---------------------------------------- | --------------------------------------------------------- |
| API Key plaintext → SHA-256 hash         | 明文 Key 仅在创建响应中返回一次，之后仅哈希存储在 DB      |
| /auth/api-tokens → ICurrentUser          | 端点通过 ICurrentUser 获取用户 ID，确保只能管理自己的 Key |
| GlobalExceptionHandler → response format | 根据路径前缀选择响应格式，不影响安全控制                  |

## STRIDE Threat Register

| Threat ID | Category               | Component                                | Disposition | Mitigation Plan                                                                              |
| --------- | ---------------------- | ---------------------------------------- | ----------- | -------------------------------------------------------------------------------------------- |
| T-01-15   | Information Disclosure | API Key creation response                | mitigate    | 完整 Key 仅在 Create 响应中返回一次（`ApiTokenCreateResult.Token`），后续 List 仅返回 Prefix |
| T-01-16   | Elevation of Privilege | RevokeApiTokenEndpoint                   | mitigate    | 端点验证 `token.UserId == currentUser.UserId`，用户只能撤销自己的 Key                        |
| T-01-17   | Spoofing               | ApiTokenService.ValidateAndGetOwnerAsync | mitigate    | 使用 SHA-256 哈希比对，不信任客户端传入的任何身份信息；Claims 完全由 DB 查询结果构建         |
| T-01-18   | Tampering              | OAuth Provider Settings CRUD             | mitigate    | 管理端点需要管理员权限（RequirePermission）；ClientSecret 在 DTO 中不返回                    |
| T-01-19   | Information Disclosure | PlanePagedResult URL construction        | accept      | next/previous URL 基于当前请求的 Path 和 QueryString 构建，不包含敏感信息                    |
