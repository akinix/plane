<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Database ↔ Application | 实体数据通过 EF Core 参数化查询访问，防止 SQL 注入 |
| API Key plaintext → SHA-256 hash | 明文 Key 仅在创建时生成并返回一次，数据库仅存储哈希值 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-06 | Information Disclosure | APIToken.TokenHash | mitigate | 数据库仅存储 SHA-256 哈希（MaxLength=64），明文 Key 仅在 Create 响应中返回一次 |
| T-01-07 | Information Disclosure | OAuthProviderSettings.ClientSecret | mitigate | DTO 中不包含 ClientSecret 字段（OAuthProviderSettingsDto 无 Secret 属性）；EF 查询默认不选择未映射到 DTO 的字段 |
| T-01-08 | Tampering | APIToken.IsActive | mitigate | 属性为 private set，仅通过 Revoke() 行为方法修改，不可从外部直接设置 |
| T-01-09 | Information Disclosure | Multi-tenant API Key isolation | mitigate | APIToken 实现 IHasTenant，ApplyTenantIsolationByDefault 自动添加全局查询过滤器，租户 A 无法查询租户 B 的 API Key |
</threat_model>
