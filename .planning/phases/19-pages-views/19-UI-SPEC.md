## Spacing Scale

Carries forward from Phase 18 UI-SPEC (Tailwind CSS v4 defaults, multiples of 4):

| Token | Value | Usage                                                       |
| ----- | ----- | ----------------------------------------------------------- |
| xs    | 4px   | Icon gaps, page card status dot spacing, favorite star gaps |
| sm    | 8px   | Compact element spacing, page card inner padding tight      |
| md    | 16px  | Default element spacing, card inner padding, button padding |
| lg    | 24px  | Section padding, page list card padding, editor padding     |
| xl    | 32px  | Layout gaps between content areas, page from sidebar margin |
| 2xl   | 48px  | Major section breaks, empty state vertical spacing          |
| 3xl   | 64px  | Page-level spacing, editor page from viewport edges         |

Exceptions:

- **Page card**: Width fixed at full container, min-height at 48px (Plane `pages/list/block.tsx` pattern)
- **Editor toolbar**: Height at 40px (Plane `pages/editor/toolbar/root.tsx` pattern — compact toolbar)
- **Page header**: Access badge + favorite icon buttons at 28px touch targets (Plane convention)
- **View list item**: Compact 44px height (Plane `views/view-list-item.tsx` pattern)
- **Empty state**: Centered with padding 64px top/bottom

### Accent Reserved For (Phase 19 additions in bold)

1. "创建页面" / "新建视图" primary CTA buttons
2. Active Tab indicator (公开/私人/已归档 in Page list; 全部/我创建的 in View list)
3. Link text (`text-custom-primary-100`)
4. Favorite star toggle active state (filled accent, empty grey)
5. **Page editor: focus ring on selected block, active toolbar button indicator**
6. **View access badge: PUBLIC/PUBLIC badge uses accent blue**
7. Selected item border in view selector dropdown
8. Save/submit button in Page/View creation modal
9. Filter active state text ("清除筛选" link)
10. Page lock icon (locked as accent green, unlocked as grey)

## Interaction Contract

### Page List Page (PAGE-01, PAGE-04, PAGE-05)

| Interaction           | Behavior                                                                                              |
| --------------------- | ----------------------------------------------------------------------------------------------------- |
| Tab switching         | Three tabs: 公开 / 私人 / 已归档 (internal state via MobX PageStore.activeTab, no route change)       |
| Create Page           | Click "创建页面" -> Modal opens with PageForm (name, logo/emoji picker, access toggle Public/Private) |
| Page tile click       | Click page tile -> navigates to independent editor page (`:workspaceSlug/pages/:pageId`)              |
| Page tile display     | Each tile shows: logo/emoji icon, name, access badge (Public/Private), favorite star, updated date    |
| Favorite toggle       | Click star icon -> optimistic update via usePageMutations.favorite -> star fills with accent color    |
| Search input          | Debounced text search (300ms) filtering page list by name, client-side from TanStack Query cache      |
| Sort dropdown         | Sort by: name / 创建时间 / 更新时间 / 最近打开 (asc/desc)                                             |
| Empty state (per tab) | Each tab shows distinct empty state message (see Copywriting Contract)                                |
| Hover actions         | Hover on tile: shows "收藏/已收藏" icon highlight + "更多" (PageDropdownActions)                      |
| More menu             | Dropdown: 复制链接, 归档 (on public/private tabs), 恢复 (on archived tab), 删除                       |
| Archive page          | More menu -> "归档" -> confirmation modal -> state moves to archived tab                              |
| Restore page          | In archived tab, More menu -> "恢复" -> immediate restoration + undo toast                            |
| Delete page           | More menu or editor -> "删除" -> confirmation modal -> permanent delete                               |
