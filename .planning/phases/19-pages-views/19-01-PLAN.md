    2. 创建 `use-pages.ts`（参考 use-modules.ts 模式），per D-P19-09：

    `usePages(workspaceId: string)`:
    - queryKey: `["pages", workspaceId]`
    - queryFn: `MOCK_PAGES.filter(p => p.workspace === workspaceId && !p.archived_at)`
    - delay 250ms, enabled: !!workspaceId

    `usePageDetail(workspaceId: string, pageId: string)`:
    - queryKey: `["pages", workspaceId, pageId]`
    - queryFn: find by id
    - delay 200ms, enabled: !!workspaceId && !!pageId

    `useArchivedPages(workspaceId: string)`:
    - queryKey: `["pages", "archived", workspaceId]`
    - queryFn: `MOCK_PAGES.filter(p => p.workspace === workspaceId && p.archived_at)`
    - delay 250ms

    3. 创建 `use-page-mutations.ts`（参考 use-module-mutations.ts 模式），per D-P19-05：

    `usePageMutations()` — 返回对象：

    `createPage`:
    - mutationFn: `(data: Partial<TPage>)` → 生成新 page（id: `page-mock-${Date.now()}`），填充默认值，push 到 MOCK_PAGES
    - 默认值：access 默认为 EPageAccess.PUBLIC, is_favorite: false, is_locked: false, owned_by: "user-1"
    - created_at/updated_at: new Date().toISOString()

    `updatePage`:
    - mutationFn: `({ pageId, data }: { pageId: string; data: Partial<TPage> })` → findIndex + Object.assign + updated_at
    - 支持部分更新（名称、描述、访问权限等）

    `deletePage`:
    - mutationFn: `(pageId: string)` → splice 从 MOCK_PAGES

    `archivePage`:
    - mutationFn: `(pageId: string)` → set archived_at = new Date().toISOString()（软归档）
    - 不是删除，只是标记归档

    `restorePage`:
    - mutationFn: `(pageId: string)` → set archived_at = null（恢复）

    `favoritePage`:
    - mutationFn: `({ pageId, is_favorite }: { pageId: string; is_favorite: boolean })` → toggle is_favorite
    - optimistic update 支持

    所有 mutations 成功后调用 `queryClient.invalidateQueries({ queryKey: ["pages"] })`
