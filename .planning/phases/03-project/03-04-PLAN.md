    **AddMember** — POST /workspaces/{slug}/projects/{projectId}/members/:
    - Endpoint: Route parameter `projectId` (Guid). Authz: `.RequireWorkspaceRole(WorkspaceRole.Admin)` (workspace Admin minimum, or project Admin checked in handler). Sets command.ProjectId + CurrentUserId from route/user. Returns 201.
    - Handler: Checks caller is project Admin (ProjectMember role=Admin) OR workspace Admin. Checks target user is not already an active member (409 if exists). Creates `ProjectMember.Create(projectId, userId, role)` and saves. Returns `AddMemberResponse`.
    - Validator: UserId required non-empty. Role must be 5, 15, or 20 (WorkspaceRole values). ProjectId required.

    **ListMembers** — GET /workspaces/{slug}/projects/{projectId}/members/:
    - Endpoint: Route parameter `projectId` (Guid). Authz: `.RequireWorkspaceRole(WorkspaceRole.Member, WorkspaceRole.Admin)` (workspace members can view project members). Sets command.ProjectId from route. Builds BaseUrl from HttpRequest. Returns 200 with PlanePagedResult<ProjectMemberDto>.
    - Handler: Two-phase batch lookup following Workspace.ListMembersQueryHandler pattern per D-04/D-05 batch resolution (RESEARCH):
      - Phase 1: Page member rows from `ProjectDbContext.Members.AsNoTracking()` filtered by ProjectId and !IsDeleted. Include active members listing (IsActive may or may not be filtered based on handler discretion — per CONTEXT Claude's discretion).
      - Phase 2: Collect distinct UserIds, batch-call `IUserIdentityService.GetUsersByIdsAsync(userIds, ct)` — single call per list (NFR-1/N+1 prevention).
      - Phase 3: Zip members with resolved UserSummary into `ProjectMemberDto` items. Use `PlanePagedResultFactory.FromPagedResponse(paged, baseUrl)` for pagination.
    - Validator: ProjectId required.

    **UpdateMemberRole** — PATCH /workspaces/{slug}/projects/{projectId}/members/{memberId}/:
    - Endpoint: Route parameters `projectId`, `memberId` (both Guid). Authz: `.RequireWorkspaceRole(WorkspaceRole.Admin)` (workspace Admin minimum). Sets command.ProjectId + MemberId from route. Returns 200.
    - Handler: Fetches member by Id + ProjectId. Throws 404 if not found. Checks caller has Admin role on project OR workspace Admin. Calls `member.UpdateRole(command.Role)`. Saves. Returns 204 or updated DTO.
    - Validator: MemberId required. Role must be valid WorkspaceRole value.

    **RemoveMember** — DELETE /workspaces/{slug}/projects/{projectId}/members/{memberId}/:
    - Endpoint: Route parameters `projectId`, `memberId` (both Guid). Authz: `.RequireWorkspaceRole(WorkspaceRole.Admin)`. Sets command.ProjectId + MemberId + CurrentUserId from route/user. Returns 204.
    - Handler: Fetches member by Id. Throws 404 if not found. Checks caller is project Admin OR workspace Admin. Calls `member.Deactivate()` (is_active=false — NOT soft delete, keeps row for audit per D-04). Cannot remove the last Admin member (guard prevents removing self if last Admin). Saves. Returns 204.
    - Validator: MemberId required.
    - Note: Cannot self-remove if the caller would leave the project with zero Admin members. Handler checks this before deactivation.
