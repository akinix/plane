  <action>
    1. 在 `package.json` 中添加依赖 `@tanstack/react-query@^5.0.0`（使用 `pnpm add` 安装）。

    2. 创建 `app/store/types.ts`，定义全局 Store 接口扩展：
    - `IWorkspaceStore` 接口：workspaces（IWorkspace[]），currentWorkspaceId（string|null），sidebarCollapsed（boolean），expandedWorkspaceIds（string[]），workspaceSwitcherOpen（boolean），setSidebarCollapsed（action），setCurrentWorkspace（action），setWorkspaceSwitcherOpen（action），toggleWorkspaceExpand（action）。
    - `IProjectStore` 接口：projects（IProject[]），expandedProjectIds（string[]），projectFilterText（string），setExpandedProject（action），setProjectFilterText（action）。
    - WorkspaceStore 和 ProjectStore 使用 MobX 的 makeObservable + observable + action + computed 模式（完全参考 AuthStore）。UI 状态（collapsed、expanded、open）使用 observable.ref，setter 方法使用 action 标注。这些 store 只管理 UI 状态，不管理服务端数据（per D-P15-08）。

    3. 创建 `app/store/workspace.store.ts`：
    - 类名：`WorkspaceStore`，实现 `IWorkspaceStore`
    - 初始值：sidebarCollapsed = false，workspaceSwitcherOpen = false，expandedWorkspaceIds = []，currentWorkspaceId = null
    - 方法：setSidebarCollapsed（toggle boolean），setCurrentWorkspace（id: string），setWorkspaceSwitcherOpen（open: boolean），toggleWorkspaceExpand（id: string — 在 expandedWorkspaceIds 中切换）
    - MakeObservable 标注所有属性和方法。

    4. 创建 `app/store/project.store.ts`：
    - 类名：`ProjectStore`，实现 `IProjectStore`
    - 初始值：expandedProjectIds = []，projectFilterText = ""
    - 方法：setExpandedProject（id: string — expandedProjectIds 切换），setProjectFilterText（text: string）

    5. 更新 `app/store/root.store.ts`：
    - 导入 WorkspaceStore 和 ProjectStore
    - 在 ICoreRootStore 接口中添加 workspace（IWorkspaceStore）和 project（IProjectStore）
    - 在 CoreRootStore constructor 中添加 `this.workspace = new WorkspaceStore()` 和 `this.project = new ProjectStore()`

    6. 更新 `app/provider.tsx`：
    - 导入 `QueryClient` 和 `QueryClientProvider` 从 `@tanstack/react-query`
    - 创建 QueryClient 实例（默认配置：staleTime: 5 * 60 * 1000，retry: 1）
    - 使用 React.useState 创建 queryClientRef（只在组件挂载时创建一次）
    - 在 StoreProvider 外层包裹 QueryClientProvider
    - 保留 AuthInitializer 在 QueryClientProvider 内部

  </action>
