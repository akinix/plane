# Phase 16 — UI Design Contract

> Visual and interaction contract for Issue 列表/详情 & 看板. Generated by gsd-ui-researcher.

---

## Design System

| Property          | Value                                                                     |
| ----------------- | ------------------------------------------------------------------------- |
| Tool              | Plane Tailwind CSS v4 (CSS custom properties)                             |
| Preset            | `@plane/tailwind-config` — `packages/tailwind-config/variables.css`       |
| Component library | `@plane/ui` (forked at `packages/ui/src/`)                                |
| Icon library      | lucide-react (primary) + Material Symbols Rounded (some Plane components) |
| Font              | Inter Variable (body + headings), IBM Plex Mono (code)                    |
| Framework         | React Router v7 (remix-flavored)                                          |

### Source of Truth

All CSS custom properties are defined in `packages/tailwind-config/variables.css`. Use semantic tokens (e.g. `bg-surface-1`, `text-primary`, `border-subtle`) — never raw hex values. The token system handles light/dark theme switching via `[data-theme="light"]` and `[data-theme="dark"]` attributes.

## Spacing Scale

The project uses Tailwind's default spacing scale, which is already 4px-based. Declared values for this phase:

| Token | Value | Usage                                  |
| ----- | ----- | -------------------------------------- |
| xs    | 4px   | Inline padding within cards, icon gaps |
| sm    | 8px   | Compact element gaps, button padding   |
| md    | 16px  | Default padding for cards, sections    |
| lg    | 24px  | Section padding, modal inner padding   |
| xl    | 32px  | Layout gaps between panels             |
| 2xl   | 48px  | Major section breaks, page padding     |
| 3xl   | 64px  | Page-level spacing                     |

Exceptions:

- **Kanban column width**: 280px per column (not on spacing scale)
- **Kanban card min-height**: 80px
- **Issue list row height**: 44px (compact row)
- **Empty state container**: min-height 320px

## Typography

| Role    | Tailwind Class            | Size | Weight | Line Height | Specific Use                                          |
| ------- | ------------------------- | ---- | ------ | ----------- | ----------------------------------------------------- |
| Display | `text-h2-semibold`        | 28px | 600    | 1.2         | Issue detail page title                               |
| Heading | `text-h4-semibold`        | 20px | 600    | 1.2         | Section headers (Comments, Activity)                  |
| Body    | `text-body-sm-regular`    | 14px | 400    | 1.4         | Issue list row content, property values, comment body |
| Label   | `text-caption-md-regular` | 12px | 400    | 1.1         | Property labels, status badges, metadata              |
| Tiny    | `text-caption-sm-regular` | 11px | 400    | 1.1         | Timestamps, issue ID prefixes                         |

**Letter-spacing**: Body uses `calc(0.01 * size)`; captions use `0`.

**The Plane token system defines full heading (h1-h6), body (md/sm/xs), and caption (md/sm/xs) variants** in 4 weights (regular/medium/semibold/bold). For this phase we constrain to the 5 roles above for consistency. When Plane components use other variants (e.g. `text-body-md-medium`), retain the plane variant — do not downgrade.

## Color

The Plane token system defines over 200 semantic color tokens across backgrounds, borders, text, icons, and links — all with light/dark variants. This contract maps the high-level 60/30/10 split and specifies accent reservation.

| Role            | Token               | Reference Value (Light)   | Usage                                                      |
| --------------- | ------------------- | ------------------------- | ---------------------------------------------------------- |
| Dominant (60%)  | `bg-canvas`         | `neutral-300` (#F5F5F7)   | App canvas background                                      |
| —               | `bg-surface-1`      | `neutral-white` (#FFFFFF) | Issue list container, detail page main panel, kanban cards |
| —               | `bg-surface-2`      | `neutral-100` (#FBFBFC)   | Secondary surfaces, filter bars                            |
| Secondary (30%) | `bg-layer-1`        | `neutral-200` (#F2F3F4)   | Sidebar property panel in detail, kanban column background |
| —               | `bg-layer-2`        | `neutral-white` (#FFFFFF) | Cards, dropdown menus, modal content                       |
| —               | `bg-layer-3`        | `neutral-300` (#E8E8EA)   | Kanban column header                                       |
| Accent (10%)    | `bg-accent-primary` | `brand-default` (#4C6FFF) | —                                                          |

| -------- | --------------------------------------------------- | ------------------------------ |

| High     | `text-color-priority-high` (orange #D97706)         | `border-color-priority-high`   |
| Medium   | `text-color-priority-medium` (amber/yellow #EAB308) | `border-color-priority-medium` |

| None     | `text-color-priority-none` (grey #9CA3AF)           | `border-color-priority-none`   |

### State Group Colors (from Plane types)

| State Group | Visual Signifier              |
| ----------- | ----------------------------- |
| Backlog     | Grey (`txt-icon-tertiary`)    |
| Unstarted   | Dimmed neutral                |
| Started     | Amber/Processing              |
| Completed   | Green (`txt-success-primary`) |
| Cancelled   | Grey with strikethrough       |

### Semantic Color Roles

| Role        | Token                                       | Use                                                            |
| ----------- | ------------------------------------------- | -------------------------------------------------------------- |
| Destructive | `bg-danger-primary` / `text-danger-primary` | Delete issue, delete comment, destructive confirmation buttons |
| Success     | `text-success-primary`                      | "Completed" state badge                                        |
| Warning     | `text-warning-primary`                      | Warning banners, urgent priority                               |
| Link        | `text-link-primary`                         | Issue ID links, clickable titles                               |
| Placeholder | `text-placeholder`                          | Input placeholders, empty state hint text                      |

### Accent Reserved For

The accent color (`bg-accent-primary` = `bg-brand-default` #4C6FFF) is reserved exclusively for:

1. **Primary action buttons** (Create Issue button, Save button)
2. **Selected/focused state** of interactive elements (active tab, selected filter chip)
3. **Checkbox selected state** in issue list selection
4. **Drag handle accent** when a kanban card is being dragged
5. **Active state indicator** in sidebar navigation for current view

**Do not** use accent color for:

- General borders or dividers
- Non-interactive decorative elements
- Status badge backgrounds (use priority/state specific colors)

## Interaction Contracts

### 1. Issue List View

| Interaction           | Behavior                                                                             |
| --------------------- | ------------------------------------------------------------------------------------ |
| **Row click**         | Navigate to `/workspaces/:workspaceId/projects/:projectId/issues/:issueId`           |
| **Checkbox click**    | Select/deselect row for bulk operations; header checkbox selects all visible rows    |
| **Filter chip click** | Apply/remove filter; active chips shown in quick filter bar                          |
| **Sort dropdown**     | Click column header or sort dropdown → select field + direction                      |
| **Pagination**        | Page controls at bottom of list; `<< < 1 2 3 ... N > >>` pattern                     |
| **View toggle**       | Tabs at top-left: List / Kanban; maintains filter state across views (D-P16-16 note) |

### 2. Issue Detail Page

| Interaction              | Behavior                                                                       |
| ------------------------ | ------------------------------------------------------------------------------ |
| **Double-column layout** | Left: 65% — description editor; Right: 35% — property sidebar                  |
| **Inline property edit** | Click property value → inline dropdown/pop-up editor appears (same as Plane)   |
| **Description edit**     | Click into area → @plane/editor activates (TipTap rich text)                   |
| **Comment create**       | Type in comment input → Submit → optimistically prepend to comment list        |
| **Comment edit**         | Hover comment → edit icon appears → click converts to inline edit mode         |
| **Comment delete**       | Click delete → confirmation dialog "确定删除此评论？"                          |
| **Delete issue**         | Click delete action → confirmation dialog "确定删除此 Issue？此操作不可撤销。" |

### 3. Kanban View

| Interaction            | Behavior                                                                                |
| ---------------------- | --------------------------------------------------------------------------------------- |
| **Column layout**      | Horizontal scrollable columns (280px each), grouped by state (default)                  |
| **Drag card**          | @hello-pangea/dnd: user drags card vertically within or between columns                 |
| **Drop on column**     | Card lands in new column → state updates to that column's state                         |
| **Group By switch**    | Dropdown to switch group: State (default) / Assignee / Priority                         |
| **Column collapse**    | Click column header chevron → collapse/expand column                                    |
| **Card quick preview** | Click card → optional: quick peek overlay (deferred if not in scope, use full navigate) |
| **Empty column**       | Column with no cards shows empty state placeholder text                                 |

### 4. Command Palette (Cmd+K)

| Interaction      | Behavior                                                               |
| ---------------- | ---------------------------------------------------------------------- |
| **Trigger**      | Press `Cmd+K` (Mac) / `Ctrl+K` (Windows) → overlay opens               |
| **Search**       | Type to search: matches issue title, issue ID, project name            |
| **Navigate**     | Select result → navigate (issue → detail page, project → project page) |
| **Keyboard nav** | `ArrowUp` / `ArrowDown` to move; `Enter` to select; `Escape` to close  |
| **Empty state**  | No results → show "没有匹配结果"                                       |

### 5. Bulk Operations

| Interaction       | Behavior                                                                           |
| ----------------- | ---------------------------------------------------------------------------------- |
| **Selection**     | Checkbox selects rows; header checkbox selects/deselects all visible               |
| **Action bar**    | Appears at bottom when >= 1 row selected                                           |
| **Available ops** | Change status (dropdown) / Change assignee (dropdown) / Delete (with confirmation) |
| **Bulk delete**   | "确定删除选中的 N 个 Issue？" — confirm button is destructive styled               |

### 6. Loading & Error States

| State              | Behavior                                                              |
| ------------------ | --------------------------------------------------------------------- |
| **Initial load**   | Spinner or skeleton rows (use `Loader` from @plane/ui)                |
| **List loading**   | Show 5 skeleton rows that match row height                            |
| **Detail loading** | Show skeleton for left + right panels                                 |
| **Error**          | Inline error banner: "加载失败，请重试" + retry button                |
| **Empty list**     | "暂无 Issue" + illustration + "创建第一个 Issue" CTA                  |
| **Empty filter**   | "没有匹配的 Issue" + "清除筛选条件" link                              |
| **Network retry**  | Error states include retry action that re-triggers the TanStack Query |

## Accessibility Requirements

| Element                  | Requirement                                                                          |
| ------------------------ | ------------------------------------------------------------------------------------ |
| All interactive controls | Must be focusable via Tab key                                                        |
| Command palette          | Full keyboard navigation (ArrowUp/Down, Enter, Escape)                               |
| Dropdown menus           | Must handle keyboard navigation + screen reader labels                               |
| Drag-and-drop            | Must provide keyboard alternative (dropdown state change) — draggable is enhancement |
| Color contrast           | Use Plane token colors which already meet WCAG AA                                    |
| Focus indicators         | Use default browser focus ring or Plane's ring-\* utilities                          |
| Screen reader            | Use `aria-label` on icon-only buttons (e.g. "关闭", "编辑", "删除")                  |
