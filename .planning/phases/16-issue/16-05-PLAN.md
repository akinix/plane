    cmdk 版本 ^1.1.1 已经在 Plan 16-01 中安装。

    组件结构：

    Step 1: 组件 props 和 state：
    ```typescript
    interface CommandPaletteProps {
      workspaceId?: string | null;
    }
    ```
    - open: boolean（控制对话框显示/隐藏）
    - 监听键盘事件：useEffect 注册 window keydown listener：
      - 按 Cmd+K（Mac）或 Ctrl+K（Windows）时 setOpen(true)
      - 在 useEffect cleanup 中移除 listener
    - 搜索数据源：
      a) Issue 标题搜索：从 MOCK_ISSUES 中搜索（name 包含 searchQuery）
      b) 项目名称搜索：从 MOCK_PROJECTS 中搜索（name 包含 searchQuery）
    - navigate: 使用 useNavigate()

    Step 2: 渲染结构（per RESEARCH.md Pattern 4）：
    ```typescript
    <Command.Dialog open={open} onOpenChange={setOpen} label="命令面板">
      <Command.Input placeholder="搜索 Issue 或页面..." />
      <Command.List>
        <Command.Empty>没有匹配结果</Command.Empty>

        <Command.Group heading="Issues">
          {filteredIssues.map((issue) => (
            <Command.Item
              key={issue.id}
              onSelect={() => {
                setOpen(false);
                navigate(`/workspaces/${wsId}/projects/${issue.project_id}/issues/${issue.id}`);
              }}
            >
              <ListTodo className="size-4" />
              <span>{issue.name}</span>
              <span className="text-xs text-custom-text-400 ml-auto">
                {getProjectIdentifier(issue.project_id)}-{issue.sequence_id}
              </span>
            </Command.Item>
          ))}
        </Command.Group>

        <Command.Group heading="项目">
          {filteredProjects.map((project) => (
            <Command.Item
              key={project.id}
              onSelect={() => {
                setOpen(false);
                navigate(`/workspaces/${wsId}/projects/${project.id}`);
              }}
            >
              <LayoutGrid className="size-4" />
              <span>{project.name}</span>
            </Command.Item>
          ))}
        </Command.Group>
      </Command.List>
    </Command.Dialog>
    ```

    Step 3: 搜索过滤逻辑：
    - 在输入值变化时过滤 MOCK_ISSUES 和 MOCK_PROJECTS
    - 大小写不敏感的包含匹配
    - 最多显示 10 个 Issue 结果和 5 个项目结果
    - 使用 useMemo 优化过滤性能

    Step 4: 键盘导航行为（per UI-SPEC.md Interaction Contracts）：
    - ArrowUp / ArrowDown 移动选择（cmdk 内置）
    - Enter 选中（cmdk 内置，onSelect 处理）
    - Escape 关闭（Command.Dialog 内置）
    - 选中后自动关闭面板并导航

    Step 5: 样式：
    - Command.Dialog 使用 backdrop blur + 半透明遮罩覆盖
    - Command.Input 使用搜索样式（左侧 lucide-react Search 图标）
    - Command.Group heading 使用 text-caption text-custom-text-400
    - Command.Item 使用 hover bg-custom-background-80
    - 整体容器使用 bg-surface-1 背景
    - 使用语义 token，跟随 @plane/tailwind-config 主题

    Step 6: 空状态和加载：
    - 无匹配时显示 "没有匹配结果"（如 UI-SPEC.md copywriting）
    - 数据加载中显示 Loading spinner（但 mock 数据为同步，无需异步加载处理）
