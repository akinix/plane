  <action>
    遵循 established TanStack Query v5 模式创建以下 hook 文件：

    src/lib/hooks/use-issues.ts:
    - import: @tanstack/react-query（useQuery, useMutation, useQueryClient），@plane/types（TIssue, TBulkIssueProperties），及 MOCK_ISSUES、MOCK_STATES、MOCK_LABELS
    - const delay(ms: number) 辅助函数（与 use-workspaces.ts 相同，300ms 默认延迟）
    - export useIssues(projectId: string, filters?: { state?: string[]; priority?: string[]; assignee?: string[]; searchQuery?: string }):
      useQuery&lt;TIssue[]&gt;，queryKey: ["issues", projectId, filters]，queryFn 中先 await delay(300)，然后从 MOCK_ISSUES 按 project_id 过滤，如果 filters 有值则进一步过滤（state: 匹配 state_id；priority: 匹配 priority；assignee: 匹配 assignee_ids 含任意；searchQuery: name 包含），enabled: !!projectId
    - export useIssue(projectId: string, issueId: string):
      useQuery&lt;TIssue | undefined&gt;，queryKey: ["issues", projectId, issueId]，queryFn 中 await delay(200)，在 MOCK_ISSUES 中 find，enabled: !!projectId && !!issueId
    - export useIssueMutations():
      返回 { createIssue, updateIssue, deleteIssue, bulkUpdateIssues } 四个 mutation 函数
      - createIssue: useMutation，mutationFn 接收 data: Partial&lt;TIssue&gt;，生成新 id 和 sequence_id，推入 MOCK_ISSUES（临时），onSuccess 后 invalidateQueries(["issues"])
      - updateIssue: useMutation，mutationFn 接收 { issueId, data: Partial&lt;TIssue&gt; }，查找并更新 MOCK_ISSUES，带 onMutate 乐观更新（查 Phase 15 的 useMutation 是否有乐观模式——如果没有，简单 invalidate 即可），onSettled invalidate
      - deleteIssue: useMutation，mutationFn 接收 issueId: string，设置 archived_at 而非移出数组（软删除），invalidate queries
      - bulkUpdateIssues: useMutation，mutationFn 接收 TBulkOperationsPayload（{ issue_ids, properties }），遍历更新各 Issue，invalidate queries

    src/lib/hooks/use-comments.ts:
    - import: 同上 + MOCK_COMMENTS
    - export useComments(issueId: string): useQuery&lt;TIssueComment[]&gt;，从 MOCK_COMMENTS[issueId] 返回，delay 200ms，enabled: !!issueId
    - export useCreateComment(): useMutation，mutationFn 接收 { issueId: string, data: Partial&lt;TIssueComment&gt; }，构造完整 comment 对象推入 MOCK_COMMENTS[issueId]
    - export useUpdateComment(): useMutation，mutationFn 接收 { issueId: string, commentId: string, data: Partial&lt;TIssueComment&gt; }
    - export useDeleteComment(): useMutation，mutationFn 接收 { issueId: string, commentId: string }

    src/lib/hooks/index.ts:
    - 在文件末尾新增两行： export * from "./use-issues"; export * from "./use-comments";
