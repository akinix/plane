    **ViewDtoMapper.cs** (`YH.Modules.View.Features.v1.Views`):
    - 使用别名: `using ViewEntity = YH.Modules.View.Domain.View;`
    - 命名空间: `YH.Modules.View.Features.v1.Views`
    - `internal static class ViewDtoMapper`:
      - `ToDto(ViewEntity v)` -- ViewDto:
        映射 Id, Name, Description, Access = (int)v.Access, SortOrder, LogoProps, OwnedBy, IsLocked, ArchivedAt, ProjectId, CreatedAt = v.CreatedOnUtc, UpdatedAt = v.LastModifiedOnUtc
      - `ToDetailDto(ViewEntity v)` -- ViewDetailDto:
        调用 ToDto 设置基础字段，然后设置 Query, Filters, DisplayFilters, DisplayProperties, RichFilters

    **CreateViewEndpoint** (`POST /`):
    - 模式与 CreatePageEndpoint 完全相同
    - 接收 `CreateViewCommand` + `ClaimsPrincipal user` + `IMediator mediator` + `Guid projectId` (路由参数)
    - 从 `user.GetUserId()` 获取 OwnedBy，设置 `command.OwnedBy = Guid.Parse(userId)`
    - 从路由 {projectId} 获取 projectId，设置 `command.ProjectId = projectId`
    - 返回 `TypedResults.Created(...)` 201
    - **`.RequireWorkspaceRole(WorkspaceRole.Admin, WorkspaceRole.Member)`**
    - 使用 RouteHandlerBuilder pattern: `internal static RouteHandlerBuilder MapCreateViewEndpoint(this IEndpointRouteBuilder endpoints) { return endpoints.MapPost("/", ...)... }`

    **CreateViewCommandHandler** -- 实现 `ICommandHandler<CreateViewCommand, CreateViewResponse>`:
    - 构造注入 `ViewDbContext _db`
    - Handle 流程:
      1. 验证 command.OwnedBy != Guid.Empty
      2. 调用 `View.Create(name, ownedBy, projectId, description, filters, displayFilters, displayProperties, richFilters, access, sortOrder, logoProps)`
      3. `_db.Views.Add(view)`
      4. `await _db.SaveChangesAsync(cancellationToken)`
      5. 返回 `new CreateViewResponse(view.Id)`
    - **注意**: CreateViewCommand 的 ProjectId 可能是 null（工作区级视图时），且 OwnedBy 由 Endpoint 从 ClaimsPrincipal 设置

    **CreateViewCommandValidator** -- `FluentValidation.AbstractValidator<CreateViewCommand>`:
    - RuleFor(x => x.Name).NotEmpty().MaximumLength(255)
    - RuleFor(x => x.OwnedBy).NotEmpty()

    **GetViewEndpoint** (`GET /{viewId}`):
    - `MapGet("/{viewId}", async (Guid viewId, IMediator mediator, ...) => ...)`
    - 返回 `TypedResults.Ok(await mediator.Send(new GetViewQuery { ViewId = viewId }))`
    - `.RequireAuthorization()` （获取 view 需要认证）

    **GetViewQueryHandler** -- `IQueryHandler<GetViewQuery, ViewDetailDto>`:
    - 构造注入 `ViewDbContext _db`
    - 查询: `_db.Views.AsNoTracking().FirstOrDefaultAsync(v => v.Id == query.ViewId && !v.IsDeleted)`
    - 如果 null -- throw NotFoundException
    - 返回 `ViewDtoMapper.ToDetailDto(view)`
    - **注意**: View 是 IGlobalEntity（无 TenantId），所以不需要 tenant 过滤

    **UpdateViewEndpoint** (`PATCH /{viewId}`):
    - `MapPatch("/{viewId}", async (Guid viewId, UpdateViewCommand command, IMediator mediator, ...) => ...)`
    - 设置 `command.ViewId = viewId`（[JsonIgnore]，从路由提取）
    - 返回 `TypedResults.Ok(await mediator.Send(command))`
    - `.RequireWorkspaceRole(Admin, Member)`

    **UpdateViewCommandHandler** -- `ICommandHandler<UpdateViewCommand, ViewDetailDto>`:
    - 构造注入 `ViewDbContext _db`
    - 加载: `_db.Views.FirstOrDefaultAsync(v => v.Id == command.ViewId && !v.IsDeleted)` -- throw NotFoundException if null
    - 调用 `view.Update(name, description, filters, displayFilters, displayProperties, richFilters, access, sortOrder, logoProps, isLocked)`
    - Verify Private view access: 如果 view.Access == Private 且当前用户不是 OwnedBy，则 throw ForbiddenException
    - `await _db.SaveChangesAsync(cancellationToken)`
    - 返回 `ViewDtoMapper.ToDetailDto(view)`

    **UpdateViewCommandValidator**:
    - RuleFor(x => x.ViewId).NotEmpty()
    - Name 非空验证（如果提供）: When(x => x.Name != null, () => RuleFor(x => x.Name).NotEmpty().MaximumLength(255))

    **DeleteViewEndpoint** (`DELETE /{viewId}`):
    - `MapDelete("/{viewId}", async (Guid viewId, IMediator mediator, ...) => ...)`
    - `.RequireWorkspaceRole(Admin, Member)`
    - 返回 `TypedResults.NoContent()`

    **DeleteViewCommandHandler** -- `ICommandHandler<DeleteViewCommand, bool>`:
    - 加载 View -- throw NotFoundException if null
    - `view.SoftDelete(DateTimeOffset.UtcNow)`
    - `await _db.SaveChangesAsync(cancellationToken)`
    - 返回 true

    **DeleteViewCommandValidator**:
    - RuleFor(x => x.ViewId).NotEmpty()

    **ListViewsEndpoint** (`GET /` - 在项目级路由组下):
    - `MapGet("/", async ([AsParameters] ListViewsQuery query, IMediator mediator, ...) => ...)`
    - 使用 `[AsParameters]` 绑定查询参数到 `ListViewsQuery`
    - `query.ProjectId` 从路由 {projectId} 提取
    - `query.WorkspaceScope = false`（项目级）
    - `.RequireWorkspaceRole(Admin, Member)`
    - 返回 `TypedResults.Ok(await mediator.Send(query))`

    **ListViewsQueryHandler** -- `IQueryHandler<ListViewsQuery, List<ViewDto>>`:
    - 构造注入 `ViewDbContext _db`
    - 查询基础: `_db.Views.AsNoTracking().Where(v => !v.IsDeleted)`
    - 筛选逻辑:
      - `query.WorkspaceScope == true` -- `.Where(v => v.ProjectId == null)` （工作区级）
      - `query.WorkspaceScope == false` -- `.Where(v => v.ProjectId == query.ProjectId)` （项目级）
      - `query.Archived.HasValue && query.Archived.Value == true` -- `.Where(v => v.ArchivedAt != null)`
      - `query.Archived.HasValue && query.Archived.Value == false` -- `.Where(v => v.ArchivedAt == null)`
      - 默认不筛选 archived（返回所有，包括已归档）
    - 排序: `.OrderBy(v => v.Name).ThenByDescending(v => v.CreatedOnUtc)`（Plane 行为）
    - 分页: `.Skip((query.PageNumber - 1) * query.PageSize).Take(query.PageSize)`
    - 映射: `.Select(v => ViewDtoMapper.ToDto(v)).ToListAsync()`
    - 注意: View 是 IGlobalEntity，无 tenant 自动过滤

    **WorkspaceViewsListEndpoint** (`GET /` - 在工作区级路由组下):
